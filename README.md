# Test application
Test application with unit tests for the [group-into-intervals module](https://github.com/mariamair/group-into-intervals)

The application runs the unit tests and logs the test results to the console and markdown files.
- See [summary.md](/reports/summary.md) for a summary of the test results.
- See [report.md](/reports/report.md) for detailed test results.
- Use the Live Server extension to display the coverage report found in the coverage folder in your local repo.

## Usage
Run the tests with `npm start`.

Use the Live Server extension to display the frontend.
